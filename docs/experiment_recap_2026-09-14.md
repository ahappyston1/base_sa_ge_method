# SAGE / PPFPSL 联邦半监督实验复盘

更新时间：2026-09-14

## 1. 固定实验背景

- 数据集：CIFAR-10，Dirichlet `alpha=0.1`
- 骨干：项目原有 ResNet-8，scaling=4
- 联邦：20 个客户端，每轮在线 8 个客户端，本地 5 个 epoch
- 每类有标签样本：500
- 主要随机设置：模型 seed=7，划分 seed=0，抽样 seed=7
- 研究约束：优先保留原骨干和数据划分，不使用外部预训练来制造不公平优势

项目把无标签样本分成 A/B/C：A 学高置信硬伪标签；B 学软一致性目标；C 主要表示证据不足或类别冲突。几何原型由有标签特征建立，用于判断样本是否符合预测类别。

## 2. 最初的实验判断

先比较了学习率和 trusted：

- LR=0.10：整体较低。
- trusted + LR=0.10：比对应老几何略好，但不是最佳。
- trusted + LR=0.15：原始 300 轮方案中最好。
- 老几何 + LR=0.20：学习能力更强但震荡明显，整体退步。
- 老几何 + LR=0.15 + 500 轮：完整结果最高约 86.53%，最终约 86.50%，说明延长训练可能有价值，但计算预算不同，不能直接当作 300 轮公平比较。

原始 `trusted_lr015`：最高约 85.83%（第 296 轮），最终约 85.64%，最后 30 轮平均约 85.507%。

## 3. trusted 的作用与局限

trusted 不直接替换分类器伪标签，而是根据几何参考给 A 组分配权重。样本越不像预测类别，训练权重越低。

它的好处是能识别一部分高风险伪标签；但“离类别中心远”不等于“分类器答案错误”。侧脸、远处、特殊姿态的正确样本也可能离中心较远。统一规则还无法充分处理不同类别的难度差异。

## 4. early trusted 实验

early 只把 trusted 权重提前：第 31—60 轮从 0 平滑增加到 1，之后完全启用。A/B/C 路由、LR=0.15、原型损失和 FedAvg 保持不变。

完整 300 轮结果：

- 最高：86.03%，第 284 轮。
- 最终：85.78%。
- 最后 30 轮平均：85.732%。
- 对照 trusted_lr015 最后 30 轮平均：85.507%。
- 最后 30 轮中，early 有 29 轮高于原版同轮。

early 有小幅持续收益，但没有解决第 83 轮暴跌：early 约从 74.11% 降到 60.94%，下降 13.17 个百分点；原版约下降 13.39 个百分点。因此不能把问题归因于 trusted 启用太晚。

## 5. 几何审计的核心发现

early 最后 30 轮 A 组访问统计：

- 几何支持组正确率约 98.18%。
- 几何反对组正确率约 82.27%。
- 参考缺失组正确率约 95.11%。

结论是：原型有区分能力，但几何反对不等于伪标签错误。反对组中大多数答案仍然正确，因此全部重罚会误伤正确样本。

反对组中，正确样本平均权重约 0.759，错误样本平均权重约 0.631，说明当前几何有一定选择性但还不够精准。猫、狗、青蛙的 A 组质量相对较低，三类合计约占 A 错误权重的 47%。这些是训练访问统计，不是测试集逐类准确率。

在同一高置信区间内，几何支持约 94.20% 正确，反对约 74.90% 正确。冲突 C 中，原型答案约 46.66%，分类器答案约 37.47%，原型略好但仍不足以批量替换硬标签。

## 6. 第 83 轮震荡调查

`updates.csv` 和 `client_updates.csv` 没有显示第 83 轮出现明显异常大的参数或 BN 更新。更值得注意的是客户端质量差异：同轮某些客户端 A 组正确率约 45%—55%，另一些可达到约 88%。

当前更合理的假设是客户端数据异质性和更新方向差异，而不是单纯的更新范数爆炸。暂时不能据此断言必须更换 FedAvg，也不能保证只加范数裁剪就能解决震荡。

## 7. trusted_multi_tail 的教训

多原型、教师、几何概率融合、A 接纳变化、B/C 新目标和客户端更新处理曾被同时加入。结果明显低于 trusted_lr015，且 A 学习比例大幅下降。

主要教训：多个大改动同时加入后，失败无法定位。后续实验必须先独立改变单一机制，再考虑合并。

## 8. 当前三个新实验

### 8.1 trusted_lr015_risk：精准调整 A 组风险权重

以 early 为基础，只替换 A 的几何权重：

- `neutral`：无明显风险，权重保持 1。
- `distance`：离本类中心远，但没有可靠竞争类别，只轻扣，最高约 15%。
- `conflict`：可靠竞争类别明显占优，最高约 60%。
- `unknown`：参考不足，不扣权。

有标签查询用于风险校准，并使用先验收缩，避免少量样本造成极端权重。A 仍使用分类器硬标签；B/C、原型损失、FedAvg 和 BN 不变。

主要风险：查询样本参加过监督训练，校准可能偏乐观。新增 `risk_audit.csv` 和 `risk_calibration.csv`，同时保存第 82—84 轮更新快照。

### 8.2 trusted_lr015_bc：EMA 教师和 B/C 特征学习

A 完全保留 early 的路由、硬标签和权重。B 的软目标从学生预测逐步过渡到 EMA 教师预测，教师系数为 0.99。

同时增加同一图片不同增强之间的特征一致性：学生强增强特征匹配教师弱增强特征，使用投影头、预测头和停止梯度。C 不被强行分配硬类别，只获得特征学习信号。

它测试 B/C 是否能提供更稳定的无标签学习目标。风险是教师可能稳定错误，特征损失可能与分类损失竞争。日志增加 `L_feature_effective`、教师 B 组统计和 `bc_feature_std`。

### 8.3 trusted_lr015_prox：中期客户端参数约束

以本轮全局参数为锚点，加入：

`L_prox = 0.5 * mu(round) * sum((local_parameter - global_parameter)^2)`

调度为：第 1—30 轮关闭；31—60 轮升至 0.01；61—200 轮保持；201—250 轮降回 0；之后关闭。约束可训练参数，不约束 BN running mean/variance buffer。

其他 A/B/C、几何、原型损失、FedAvg 和 BN 保持不变。它测试客户端本地更新偏离是否是中期震荡的重要来源。约束过强可能阻碍客户端学习稀缺类别，曲线变平也不等于准确率提高。

## 9. 三个实验的比较逻辑

| 实验 | 改动位置 | 主要问题 |
|---|---|---|
| risk | A 组权重 | 几何评价过粗、误伤正确样本 |
| bc | B/C 目标和特征损失 | 不确定样本目标不稳定、C 利用不足 |
| prox | 客户端本地优化 | 客户端更新方向差异和全局震荡 |

三者先独立运行。risk 会改变后续特征和原型；BC 会改变特征表示进而改变几何；prox 会改变整个客户端训练轨迹，因此不能一开始直接合并。

判断时优先看最后 30 轮平均，同时看最高值、最终值、第 83 轮附近的下降幅度。risk 看正确/错误 A 的实际权重；BC 看教师 B 目标质量和特征损失比例；prox 看客户端更新差异是否下降。

如果某个方向有效，再设计组合。risk + BC 理论上比 prox 与其他方法更容易合并，但不能直接把两个单独实验的系数相加。

## 10. Git 与服务器流程

服务器正在写结果时，不要覆盖 CSV、日志和 checkpoint。先备份完整实验目录，尤其是 checkpoint，再提交结果文件。

本地和远程都有提交时：

```bash
git fetch origin
git merge origin/main
git push origin main
```

如果 Git 打开 Vim 填写 merge message：按 `Esc`，输入 `:wq`，回车。`:wq` 只完成本地 merge，之后还要执行 `git push origin main`。

不要使用 `git push --force`、`git reset --hard`，也不要在实验仍写入时对 `results/` 执行 checkout 或 reset。

## 11. 当前阶段结论

1. LR=0.15 是当前更合适的学习率；LR=0.20 过于激进。
2. trusted_lr015 是原始 300 轮基准中最好的方案。
3. early trusted 带来约 0.2 个百分点的后期收益，但没有解决第 83 轮震荡。
4. 原型有区分能力，但几何反对不等于错误。
5. C 不适合直接改成原型硬标签。
6. 第 83 轮更可能涉及客户端异质性和更新方向，而不只是更新幅度。
7. 多个大改动同时加入会导致不可解释的退化。

下一步：完成 risk、bc、prox 三个独立实验；按统一指标比较；只有单项确认有效后再合并。任何单项都不承诺达到 88%，需要用相同数据划分、评估口径和完整日志验证。
