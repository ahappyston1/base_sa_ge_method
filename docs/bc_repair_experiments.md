# BC 全程渐进 A 组修复实验

代码分支：`codex/bc-joint-correction`。三个新实验均从头训练 300 轮，不能从原 BC 的第 225 轮 checkpoint 分叉。原有三个后段 75 轮实验的配置和启动方式保留。

## 三个实验

1. `bc_repair_recover`：只恢复被几何扣权的 A 样本。教师两次弱增强均以至少 0.95 置信度支持原标签，并且原类别具有有效真标签参考、正的参考可信度、样本落在放宽后的参考半径内，才恢复部分权重。恢复量乘该类别参考可信度和教师一致性分数，最多恢复已扣权重的一半。第 30–90 轮余弦渐增，31 轮开始允许介入。
2. `bc_repair_correct`：只减轻可疑硬目标。两次教师预测一致且均以至少 0.90 置信度反对原标签时，以两次教师概率的均值作为软目标，最多混入 50%。第 60–120 轮余弦渐增，61 轮开始允许介入。原几何分类权重保持不变；同一批样本按原硬标签写入原型的贡献同步渐减，到 120 轮完全关闭。
3. `bc_repair_joint`：组合上述两条互斥规则，所有阈值和渐增区间与单项相同，检验两者是否互补。

三个实验均保留原 BC 的 LR=0.15、300 轮学习率日程、教师 EMA、B 目标、0.10 特征权重、路由、骨干和数据设置。没有加入正在运行的 B 重分配、A guard 或特征减半方案。只纠错实验同时包含原型写入保护，因此它检验的是这套纠错处理，不能将收益单独归因于软目标。

## 整体约束与局限

- Phase 1 提前几何扣权和 Phase 2/3 都接入了新规则；前 30 轮保持 BC。启动点对齐已有 trusted/BC 教师建立日程，但 90/120 轮和阈值仍是待验证超参数，不是数据证明的最优值。
- 恢复权重不会增加原型写入。纠错不会把教师新类别直接写成硬原型标签。trusted 的直接参考来自已有真标签，伪标签写入的是其他原型状态，不能混称同一个参考。
- 教师每轮从服务器模型初始化、轮内 EMA 更新，与原 BC 一致。双增强一致不是跨轮稳定性，也不是独立裁判；高置信度仍可能错误。
- 50% 混合通常不能将目标彻底翻到新类别，目的是减轻错误硬监督。若覆盖率很低，不能据此证明纠错方向无效。
- 类别差异只通过现有真标签参考可信度影响恢复量；没有完成独立的逐类别教师正确率校准。猫、狗、青蛙不被硬编码减权，因此能否改善其伪标签质量仍需结果证明。
- 未标注样本隐藏真值只进入诊断，不进入选择、权重、训练目标或启用日程。
- 新选项与旧 tail、风险、近端组合受到参数验证限制。checkpoint 的 geometry_controls 包含新方法元数据，防止把原 BC checkpoint 当作新实验续训。新实验自己的完整 checkpoint 仍可正常恢复。

## 运行

等待旧任务释放 GPU 后，在安装了 torch 的 Python 环境执行。以下示例需要 GPU 0、1 均已空闲：

```bash
python scripts/run_bc_repair.py --gpus 0 1 --dry-run
nohup python -u scripts/run_bc_repair.py --gpus 0 1 > bc_repair_queue.log 2>&1 &
```

GPU 0 顺序运行 recover、joint，GPU 1 运行 correct；最多同时两个。若有三个空闲 GPU，使用 `--gpus 0 1 2`。单 GPU 使用 `--gpus 0`，三个依次运行。脚本不会检测旧实验是否结束，不会自动避让已占用 GPU，也不会终止任何旧进程。某条队列训练失败时，该条队列后续实验停止，其他已启动队列继续，整体返回失败。

单独选择实验：

```bash
python -u scripts/run_bc_repair.py --gpus 0 --experiments joint
```

每次启动生成唯一 run_id，训练结果写入新目录；启动日志位于 `results/bc_repair_launches/`。每个实验额外保留第 30、60、90、120、225 轮完整 checkpoint。

## 复盘重点

除 best、末 30 轮均值、末轮准确率外，比较 31–90、91–150、151–225、226–300 的走势和单轮下降，判断是否破坏 BC 中段稳定性。

`dynamics.csv` 新增每个预测类别的 `repair_c{类别号}_...` 累计访问统计：

- `recover_visits`、`recover_correct`：恢复覆盖量和恢复样本正确数。
- `added_correct_weight`、`added_wrong_weight`：恢复真正增加的正确/错误监督权重。
- `correction_visits`、`correction_fix_visits`、`correction_harm_visits`：选择量、原答案错且教师对、原答案对且教师错。fix 是候选教师方向正确，不代表混合后已经彻底改正标签。
- `old_wrong_weight`、`new_target_wrong_mass`：干预前错误硬目标质量与干预后分配给非真类的目标质量。
- `prototype_removed_correct`、`prototype_removed_wrong`：减少的原标签原型写入质量。

上述质量均为未乘外层 lambda_A 的批次累计权重，不等于梯度大小；重复访问不等于独立样本数。只有启用干预的轮次累计这些诊断。已有几何审计/伪标签精度仍以原学生硬标签定义，不能用它代替新软目标错误质量。先看单项收益、误伤和覆盖，再判断 joint 是否互补。
